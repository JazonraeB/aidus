# Security Policy

AIDUS files are designed to be committed, possibly to public repositories, so privacy and credential leaks are treated as security issues.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting instead: **Security → Report a vulnerability** on this repository.

Relevant reports include:
- a way for a conformant writer to emit prompts, code, credentials or personal data
- a credential pattern the validator misses
- a fixture that contains real data.

Expect an acknowledgement within 7 days.

## Scope

This policy covers the spec, schemas, fixtures, reference tests and the `aidus` CLI in this repository.
